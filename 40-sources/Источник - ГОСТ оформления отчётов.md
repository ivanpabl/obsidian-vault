# Источник - ГОСТ оформления отчётов

## Что это

Правила оформления отчётов по лабам и практическим работам по ИБ (ГОСТ-стиль). Рабочая реализация — генератор отчётов `documents/otchet_lab/report/generate.js` (Node.js + docx).

## Рабочие правила

- Times New Roman; основной текст 14 pt, малый 12 pt
- межстрочный интервал 1,5; абзацный отступ 1,25 см; выравнивание по ширине
- H1 — по центру, жирный; H2 — жирный с отступом
- автоматическая нумерация рисунков и таблиц, оглавление, номера страниц

## Как применять

- Отчёт по лабе собирать генератором (`generate.js`), а не верстать вручную в Word.
- Для нового отчёта брать generate.js как шаблон, меняя только содержимое.

## Когда пригодится

Каждая новая лаба или практическая работа по ИБ, требующая отчёта.
